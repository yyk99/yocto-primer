TODO: run the root filesystem from the board's NOR flash
=========================================================

Status: planned, nothing built or written to the board yet. The USB stick
root is the path being done first.

Why
---
The USB stick is the easy development loop. Final goal is a board that boots
without a PC (TFTP) and without a stick: kernel and root filesystem in the
16 MB NOR flash.

Flash map today (RedBoot "fis list", flash 0x60000000-0x61000000)
------------------------------------------------------------------
RedBoot           0x60000000  0x00040000   keep
netbsd            0x60040000  0x00500000   reuse
netbsd_install    0x60540000  0x00500000   reuse
ramdisk.gz        0x60A40000  0x00300000   keep (stock Linux, recovery)
zImage            0x60D40000  0x00180000   keep (stock Linux, recovery)
free              0x60EC0000  0x00100000   optional JFFS2 data later
RedBoot config    0x60FC0000  0x00001000   keep
FIS directory     0x60FE0000  0x00020000   keep

Reusing the two NetBSD slots (10 MB contiguous) loses the stock NetBSD
images. The DVD copy has them. The stock Linux boot stays as the recovery.

New partitions inside the 10 MB
-------------------------------
kernel   0x60040000  0x300000 (3 MB)  zImage-ep9301-olimex.dtb.bin (2.47 MB)
rootfs   0x60340000  0x700000 (7 MB)  read-only SquashFS image

Build changes needed
--------------------
- IMAGE_FSTYPES += "squashfs" (default gzip; xz would decompress slowly on
  the ARM920T). Expect 3-4 MB, must fit in 7 MB.
- Kernel options in files/defconfig: MTD_BLOCK, MTD_REDBOOT_PARTS, SQUASHFS,
  OVERLAY_FS (or TMPFS for a writable /var and /tmp).
- MTD_REDBOOT_PARTS makes the kernel read the FIS directory itself, so no
  mtdparts= is needed. Get the real mtdN numbers from the boot log before
  writing root=.

Flash steps (once, from RedBoot)
--------------------------------
1. Load the kernel into RAM over TFTP, check cksum.
2. fis delete netbsd ; fis delete netbsd_install
3. fis create -b 0x00080000 -r 0x00080000 -l 0x300000 kernel
4. Load rootfs.squashfs over TFTP, fis create it as "rootfs" at 0x60340000.
5. Verify: cksum of the flash region equals cksum of the file.
Paste "fis list" before and after. Never run "fis init" or fconfig without -l
(only the two NetBSD slots may be touched).

Boot script (fconfig, only after a manual boot works)
-----------------------------------------------------
fis load kernel
exec -r 0x800000 -s 0x800000 -c "console=ttyAM0,57600 root=/dev/mtdblock<N> rootfstype=squashfs ro"
