Open items
----------

1. Reboot ("Reboot failed -- System halted"): fixed in the kernel config.
   Cause was CONFIG_POWER_RESET off (tinyconfig), so the EP93xx restart
   driver (POWER_RESET_EP93XX, SWRST bit in DEVCFG) was not built. With
   CONFIG_POWER_RESET=y "reboot" resets into RedBoot (tested over TFTP).
   Still to do: write the new kernel into flash (the "kernel" entry has the
   old one): 2560012 bytes = 0x27100c, cksum 575642029.
   Steps: README, "Flash the kernel and boot from flash".

2. Update the kernel from the running system (no PC, no TFTP).
   - Kernel: CONFIG_MTD_REDBOOT_PARTS, so Linux reads the FIS directory and
     names the partitions; RedBoot, RedBoot config and FIS directory become
     read-only, so Linux cannot damage them.
   - Image: add mtd-utils (flashcp, flash_erase).
   - Boot script: replace "fis load kernel" with a copy of the whole 3 MB slot,
     because "fis load" copies only the length stored in the FIS entry and a
     bigger kernel written from Linux would be truncated:
         cp -b 0x60040000 -d 0x00080000 -l 0x300000
         exec -r 0x800000 -s 0x800000 -c "console=ttyAM0,57600 root=/dev/mmcblk0p1 rootwait" 0x00080000
     Test by hand in RedBoot before changing the boot script (fconfig).
   - Update: scp the bundle to the board, then flashcp -v <file> /dev/mtdN
     (N = the "kernel" partition in /proc/mtd). A power cut leaves a bad
     kernel but RedBoot is untouched: reload over TFTP.
   - One-time bootstrap with RedBoot (fis create, as before) for the first

Optional: root filesystem in flash
----------------------------------
Only needed to boot without the SD card. Free area: 0x60340000-0x60A40000
(7 MB). Build IMAGE_FSTYPES += "squashfs" (default gzip), kernel options
MTD_BLOCK, SQUASHFS and OVERLAY_FS or TMPFS (writable /var, /tmp); with
MTD_REDBOOT_PARTS the partition shows up by name, so no mtdparts= is needed.
Create it with fis create at 0x60340000, verify with cksum, then boot with
root=/dev/mtdblock<N> rootfstype=squashfs ro. Writable data could use JFFS2
in the free 1 MB at 0x60EC0000.

Rules for flash work: paste "fis list" before and after, verify every write
with cksum, never run "fis init", and only touch the "kernel" entry and the
free areas.
